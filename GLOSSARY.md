# Glossary

The project's shared vocabulary. Keep names in code and conversation aligned with these terms; add a term when a concept gets a module of its own.

- **Update flow** — every rule that decides when the app offers a reload after a new service worker version arrives: the notice shown when a worker waits, the takeover noticed when another tab applied the update, the reload triggered by the Reload button, and the hourly/foreground update check. Lives in `src/update-flow.js` behind `createUpdateFlow`; the browser wiring stays in `src/main.js`.
- **Message** — a text key plus values, turned into text only when displayed, so it appears in the right language even after a language switch. The primitive lives in `src/messages.js` (`msg`); the error and tide-status tables map errors and tide results onto it, and `viewer.js` renders messages through the i18n store.
- **Arrow sampling** — the rule that decides which grid cells carry an arrow: sample every `ceil(sqrt(visible / budget))` cells, so zooming in shows more arrows, and never draw outside the padded viewport. Lives in `src/arrows.js` (`sampleArrows`); `map.js` only projects the chosen cells into polylines.
- **Point popup** — the card shown at a tapped map point: the current there and then, its speed curve for the following hours, or a plain status line. The decision of what a query result shows lives in `src/point-popup.js` (`pointPopupPlan`), the card is DOM, and the popup lifecycle (opening it, updating it in place) stays in `map.js`.
- **Frame gate** — decides whether the frames of a draw are in memory and starts the loads when not; owns the racing so only the latest blocking request updates the loading indicator or reports an error, while a playback look-ahead (a warmer) never blocks. Lives in `src/frame-gate.js` (`createFrameGate`); `viewer.js` only mirrors the reported state.
- **Hash sync** — keeps the address bar in step with the open atlas, the map view and the time marker, and applies a pasted link to the open page: open its atlas, restore its view, or show the chooser. Writes are throttled into one trailing write and suppressed while a link is restored or no atlas is open; when two links open atlases at once, only the latest applies its view and releases the restore. Lives in `src/hash-sync.js` (`createHashSync`); the hash format is `src/url-state.js`, and `viewer.js` keeps the wiring and the map-specific view.
- **Offline plan** — the file names and URLs of one atlas's frames, derived from its meta (frame template, per-coefficient and per-time indices), so the page, the worker cache keys and the offline state all name the same files. Lives in `src/offline-plan.js` (`frameFile`, `frameUrls`, `frameUrl`, `obsoleteFrameKeys`).
- **Offline state** — what of an atlas the browser holds right now, derived on every look from the frame cache: none, partial (n of m) or complete. No flag is stored anywhere, so an eviction, a wipe or a version change cannot leave a stale "downloaded" behind. Lives in `src/offline-state.js` (`stateOf`, `cachedFrameUrls`).
- **Offline flow** — the tap flow of one Downloads row: idle → confirming (exact size shown) → running, and back; refuses a second start while one is going. Lives in `src/offline-flow.js` (`createOfflineFlow`); `viewer.js` keeps the AbortControllers and mirrors the state.
- **Offline download** — fetching an atlas's frames into the named frame cache from the page, with bounded concurrency, progress counts and resume (already cached frames are skipped, so the cache itself is the journal). Lives in `src/offline-download.js` (`createDownload`, `DownloadQuotaError`).
- **Offline meta load** — how the Downloads tab gathers every frame atlas's meta.json: one ~8 s timeout per meta, failures kept visible as a failed row with Retry, rows rendered progressively as metas settle. Lives in `src/offline-meta.js` (`loadMetasProgressively`); the row and empty-state shapes are `src/offline-rows.js`.
- **Unavailable error** — the error type for "the network said no" when reading atlas data, telling the offline-atlas message apart from a broken file. Lives in `src/unavailable-error.js` (`UnavailableError`); `messages.js` maps it onto the offline texts.
